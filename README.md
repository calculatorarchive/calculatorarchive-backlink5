## Deployment to GitHub Pages

### Step 1: Create a New Repository

1. Go to [GitHub](https://github.com) and create a new repository
2. Name it something like `backlink6-calculatorarchive` or `emi-calculator-backlink`
3. Set the repository to **Public**

### Step 2: Upload Files

1. Download or clone this repository
2. Upload `index.html` and `README.md` to your GitHub repository
3. Commit the changes

### Step 3: Enable GitHub Pages

1. Go to your repository on GitHub
2. Click on **Settings**
3. Scroll down to the **Pages** section (in the "Code and automation" section)
4. Under **Source**, select **Deploy from a branch**
5. Under **Branch**, select **main** (or **master**) and choose **/ (root)**
6. Click **Save**

### Step 4: Access Your Live Page

After a few minutes, your page will be live at:
```
https://<your-username>.github.io/<repository-name>/
```
